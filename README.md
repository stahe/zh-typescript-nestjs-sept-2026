# TypeScript 语言与 NestJS 框架入门

> ⚠️ **本仓库不是一个软件项目。** 这里没有需要安装的应用，没有需要发布的包，也没有需要修复的代码问题：这是**课程资料**，为学习 TypeScript 以及随后学习 NestJS 框架的学生而写。

阅读无需安装任何东西：只需一个浏览器。

## 🎯 本课程适合谁？

本课程面向**没有任何** TypeScript 或 NestJS 基础的学生。它从 TypeScript 语言的基础知识开始，通过大量逐行注释的完整代码示例，逐步过渡到使用 NestJS 构建完整的应用。

## 📚 课程大纲

课程分为几个主要部分：

1. **TypeScript 基础** —— 搭建开发环境、语言语法、静态类型、面向对象编程。
2. **TypeScript HTTP 函数** —— 在引入任何框架之前，先用纯 TypeScript 构建 HTTP 服务器和 HTTP 客户端。
3. **数据库访问** —— 比较三种方式：原生的 `mysql2`、[TypeORM](https://typeorm.io/) ORM 和 [Prisma](https://www.prisma.io/) ORM。
4. **NestJS 框架** —— 框架介绍、其 MVC 架构、请求处理（动作/响应）、模型层，以及使用 NestJS 访问数据。
5. **一个完整的案例研究** —— 把最初用 PHP 编写的所得税计算服务器移植到 NestJS：控制器、DAO 层和业务逻辑层、会话管理，以及使用 EJS 模板构建 HTML 页面。
