    ==

    自 2019 年以来，ECMAScript 语言发生了重大演变：ECMAScript 已经历了 2020 年至 2026 年的多个版本，而一门配套语言 [TypeScript] 已成为大规模编写 JavaScript 最安全的方式。本次改写紧密遵循原始文档 “通过示例学习 ECMASCRIPT 6 语言入门”的结构和教学方法——一个脚本、它的代码、逐行解释以及执行结果——但是：

    • 现在所有脚本都使用 [TypeScript] 编写，而不是纯 JavaScript；
    • 讲解不仅涵盖语言的语法，还涵盖其 数据类型 以及与 JavaScript 的差异；
    • 新增了若干章节，介绍 2020 年至 2026 年间引入的新特性：可选链、带私有字段的类、顶层 await、Object.groupBy、Array.fromAsync，以及 ECMAScript 2026 的最新新增内容（Math.sumPrecise、Iterator.concat、Error.isError等）；
    • 有一章专门介绍 [Temporal]，即 Date 对象的现代继任者；
    • 原始文档中的 VSCode 运行截图已被替换为 每个脚本实际、经过验证的 输出，使用 tsx 在 Node.js 26 上运行。

    与原始文档一样，本文档也涉及一个用 PHP 7 编写的税款计算服务器（参见课程“通过示例学习 PHP7 语言入门”）。最后几章用 TypeScript 构建该服务器的客户端——首先是一个控制台应用程序，使用 [UI, business, dao] 分层构建，然后是一个使用 [webpack] 在浏览器中运行的客户端。

    本文档需要 主动阅读：要理解一个脚本，必须阅读它的代码、注释以及其执行的实际结果。

    1.1. 目标读者与前置知识

    本文档面向已经熟悉另一种语言中编程基础知识（变量、循环、函数、条件结构）的 TypeScript 初学者。无需事先掌握 JavaScript 或 TypeScript。

    1.2. 示例项目的组织结构

    本文档中展示的所有脚本都属于同一个 VSCode 项目——即下文所述完整目录结构中的 typescript-fundamentals/ 文件夹——按章节组织为每章一个文件夹（basics、arrays、objects、strings、regexp、functions、exceptions、modules、async、http、classes、whats-new, ecmascript-2026, temporal, tax client）。每个脚本都是一个 .ts 文件，可以在项目根目录下通过以下命令直接运行：

    npx tsx path/to/the/script.ts
    提示：每个项目文件夹中的 README.md 文件对本文档的教学内容做了简明总结——在读完本文档后，它们可以作为快速参考。

    从数据库和 NestJS 的章节开始，本项目不再局限于上述文件夹：它现在是一个统一的、更大的目录结构的一部分，其中包含本文档介绍的所有脚本——TypeScript 基础、数据库访问、NestJS 迷你项目和案例研究。读者下载的正是这个完整的目录结构，只需在其根目录下运行一次 **npm install 命令，即可一次性安装所有内容，这要归功于 [npm workspaces]**：

    typescript-nestjs-course-scripts/
├── package.json
├── README.md
├── typescript-fundamentals/
│   ├── basics/  arrays/  objects/  strings/  regexp/  functions/
│   ├── exceptions/  modules/  async/  http/  classes/
│   └── whats-new/  ecmascript-2026/  temporal/  tax client/
├── typescript-databases/
│   ├── sql/
│   └── databases/  (mysql/  typeorm/  prisma/)
├── nestjs-course/
│   ├── hello-nest/
│   ├── actions-response/
│   ├── actions-model/
│   └── data-access/  (native-driver/  typeorm/  prisma/)
└── nestjs-case-study/
    ├── src/  (actions/  config/  entities/  filters/  model/  responses/  session/  utilities/)
    └── views/

    这些文件夹各自的用途：

    • typescript-fundamentals/ ——语言章节的脚本（即上文所述的那个：basics、arrays、objects、functions、classes、async、exceptions、modules、ECMAScript 新特性、[Temporal]，以及随后的税款计算服务器客户端）；
    • typescript-databases/ ——关于数据库访问的三章：原生 mysql2 驱动、TypeORM ORM 和 Prisma ORM；
    • nestjs-course/ ——框架章节中的 NestJS 迷你项目：hello-nest （第一个项目）、actions-response、actions-model，以及演示 NestJS 与原生驱动、TypeORM 和 Prisma 结合使用的 data-access 代码片段；
    • nestjs-case-study/ ——“案例研究”一章中的完整项目：将 PHP 税款计算服务器移植到 NestJS。

    根目录中的 README.md 文件遵循这一结构；如上所述，每个子文件夹也包含自己的 README.md 文件，其中有各自具体的运行说明。
